title: Consultar Cobrança
description: Retorna os dados completos de uma cobrança
api: "GET /payins/{id}"
---

## Descrição

Retorna os dados completos de uma cobrança, incluindo status, dados do pagador, PIX e taxa.

---

## Parâmetros de Path

<ParamField path="id" type="string" required>
  UUID da cobrança, devolvido na criação
</ParamField>

---

## Headers

<ParamField header="Authorization" type="string" required default="Bearer YOUR_API_KEY">
  Bearer token de autenticação. Formato: `Bearer YOUR_API_KEY`
</ParamField>

---

## Exemplo de Requisição

<CodeGroup>
```bash cURL
curl https://api.visepag.com/v1/payins/54e2b712-aca0-4230-b69a-d6dd8542c925 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch(
  'https://api.visepag.com/v1/payins/54e2b712-aca0-4230-b69a-d6dd8542c925',
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);
const charge = await response.json();
```

```python Python
import requests

charge = requests.get(
    'https://api.visepag.com/v1/payins/54e2b712-aca0-4230-b69a-d6dd8542c925',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
).json()
```
</CodeGroup>

## Resposta `200 OK`

<ResponseField name="id" type="string">
  UUID da cobrança.
</ResponseField>

<ResponseField name="status" type="string">
  Status atual: `creating`, `pending`, `paid`, `expired`, `failed` ou `review`.
</ResponseField>

<ResponseField name="method" type="string">
  Método de pagamento: `pix`.
</ResponseField>

<ResponseField name="amount" type="integer">
  Valor em centavos.
</ResponseField>

<ResponseField name="platformFee" type="integer">
  Taxa da VisePag, em centavos.
</ResponseField>

<ResponseField name="description" type="string">
  Descrição da cobrança.
</ResponseField>

<ResponseField name="customerName" type="string">
  Nome do pagador.
</ResponseField>

<ResponseField name="customerDocument" type="string">
  CPF ou CNPJ do pagador.
</ResponseField>

<ResponseField name="customerEmail" type="string | null">
  E-mail do pagador, ou `null`.
</ResponseField>

<ResponseField name="pixCopy" type="string">
  Código PIX copia-e-cola.
</ResponseField>

<ResponseField name="pixQrCode" type="string | null">
  Imagem do QR Code (PNG em base64), ou `null`.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data de criação em ISO 8601.
</ResponseField>

<ResponseField name="expiresAt" type="string | null">
  Data de expiração em ISO 8601, ou `null`.
</ResponseField>

<ResponseField name="paidAt" type="string | null">
  Data de pagamento em ISO 8601, ou `null`.
</ResponseField>

<ResponseField name="currency" type="string">
  Sempre `"brl"`.
</ResponseField>

<ResponseField name="livemode" type="boolean">
  Sempre `true`.
</ResponseField>

## Erros

| Status | Código | Descrição |
|--------|--------|-----------|
| `404` | `charge_not_found` | Cobrança não encontrada, ou de outra empresa |
| `401` | `missing_authorization` | Header `Authorization` ausente |
