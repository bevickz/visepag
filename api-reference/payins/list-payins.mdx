## Descrição

Retorna uma lista paginada das cobranças da empresa, criadas pela API e pelo Dashboard, com filtros por status, método e data. Os depósitos feitos na própria conta não entram na lista.

---

## Headers

<ParamField header="Authorization" type="string" required default="Bearer YOUR_API_KEY">
  Bearer token de autenticação. Formato: `Bearer YOUR_API_KEY`
</ParamField>

---

## Query Parameters

<ParamField query="limit" type="integer" default="10">
  Quantidade de resultados (mín: 1, máx: 100)
</ParamField>

<ParamField query="starting_after" type="string">
  Cursor de paginação: ID da última cobrança da página anterior
</ParamField>

<ParamField query="method" type="string">
  Filtrar por método de pagamento: `pix`
</ParamField>

<ParamField query="status" type="string">
  Filtrar por status: `creating`, `pending`, `paid`, `expired`, `failed`, `review`
</ParamField>

<ParamField query="created[gte]" type="string">
  Data mínima de criação (ISO 8601)
</ParamField>

<ParamField query="created[lte]" type="string">
  Data máxima de criação (ISO 8601)
</ParamField>

## Exemplo de Requisição

<CodeGroup>
```bash cURL
# Listar as últimas 20 cobranças pagas
curl "https://api.visepag.com/v1/payins?limit=20&method=pix&status=paid" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```bash Paginação
# Próxima página após o último ID retornado
curl "https://api.visepag.com/v1/payins?limit=10&starting_after=54e2b712-aca0-4230-b69a-d6dd8542c925" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Paginação

A API usa **cursor-based pagination** com o campo `starting_after`:

```javascript
// Buscar todas as cobranças automaticamente
async function buscarTodasCobrancas() {
  const cobrancas = [];
  let cursor = null;

  do {
    const params = new URLSearchParams({ limit: '100' });
    if (cursor) params.set('starting_after', cursor);

    const res = await fetch(`https://api.visepag.com/v1/payins?${params}`, {
      headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
    });
    const { data, has_more } = await res.json();

    cobrancas.push(...data);
    cursor = has_more ? data[data.length - 1].id : null;
  } while (cursor);

  return cobrancas;
}
```

<Note>
  Quando `has_more` é `true`, existem mais resultados. Use o `id` da última cobrança retornada como `starting_after` para buscar a próxima página.
</Note>
