## Base URL

```
https://api.visepag.com/v1
```

## Autenticação

Todas as requisições requerem o header:

```http
Authorization: Bearer YOUR_API_KEY
```

## Formato das Respostas

Todas as respostas são em `application/json`. Os campos usam camelCase, os valores (`amount`, `platformFee`) são em centavos e as datas usam o formato ISO 8601.
