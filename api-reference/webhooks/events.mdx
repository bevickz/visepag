## Handler Completo

Exemplo de como tratar todos os eventos em um único handler:

```javascript
app.post('/webhooks/visepag', express.json(), (req, res) => {
  res.status(200).end();

  const { type, data } = req.body;

  switch (type) {
    case 'transaction.paid':
      // Liberar produto/serviço
      liberarPedido(data.id, data.amount);
      break;

    case 'withdrawal.completed':
      // Confirmar saque no dashboard interno
      confirmarSaque(data.id, data.amount);
      break;

    case 'withdrawal.failed':
      // Notificar equipe financeira
      notificarFalhaSaque(data.id, data.failureReason);
      break;

    default:
      console.log(`Evento desconhecido: ${type}`);
  }
});
```
