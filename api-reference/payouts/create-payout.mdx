## Descrição

Solicita um saque do saldo disponível para a chave PIX informada. O valor sai do saldo disponível na hora e fica em processamento até a conclusão. O resultado chega pelos webhooks <code>withdrawal.completed</code> ou <code>withdrawal.failed</code>, e também pode ser consultado em <code>GET /v1/payouts/{id}</code>.

<Note>
  O campo <code>amount</code> é o valor que sai do saldo, em <strong>centavos</strong>. A taxa do saque (<code>platformFee</code>) é descontada desse valor.
</Note>

**Rate Limit:** 60 requisições/minuto

---

## Headers

<ParamField header="Authorization" type="string" required default="Bearer YOUR_API_KEY">
  Bearer token de autenticação. Formato: <code>Bearer YOUR_API_KEY</code>
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Deve ser <code>application/json</code>
</ParamField>

---

## Body

<ParamField body="amount" type="integer" required>
  Valor do saque em centavos. Precisa respeitar o mínimo de saque da conta e ser maior que a taxa.
</ParamField>

<ParamField body="pixKey" type="string" required>
  Chave PIX de destino.
</ParamField>

<ParamField body="pixType" type="string" required>
  Tipo da chave: <code>cpf</code>, <code>cnpj</code>, <code>phone</code>, <code>email</code> ou <code>random</code>.
</ParamField>

<ParamField body="description" type="string">
  Descrição do saque, até 140 caracteres. Se não for enviada, vale <code>Saque solicitado</code>.
</ParamField>

---

## Saque

### Requisição

<CodeGroup>
~~~bash cURL
curl -X POST https://api.visepag.com/v1/payouts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 5000,
    "pixKey": "52998224725",
    "pixType": "cpf",
    "description": "Saque semanal"
  }'
~~~

~~~javascript Node.js
const response = await fetch('https://api.visepag.com/v1/payouts', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 5000,
    pixKey: '52998224725',
    pixType: 'cpf',
    description: 'Saque semanal'
  })
});

const payout = await response.json();
~~~
</CodeGroup>

## Erros

| Status | Código | Descrição |
|--------|--------|-----------|
| 400 | <code>invalid_amount</code> | <code>amount</code> deve ser um inteiro positivo em centavos |
| 400 | <code>invalid_pix_key</code> | Chave PIX ausente ou inválida para o tipo |
| 400 | <code>invalid_pix_key_type</code> | Tipo de chave inválido |
| 400 | <code>invalid_description</code> | <code>description</code> com mais de 140 caracteres |
| 401 | <code>missing_authorization</code> | Header <code>Authorization</code> ausente |
| 401 | <code>invalid_api_key</code> | Chave de API inválida |
| 403 | <code>account_not_fully_verified</code> | Conta sem verificação completa (KYC) |
| 422 | <code>amount_below_minimum</code> | Valor abaixo do mínimo de saque |
| 422 | <code>amount_below_fee</code> | Valor precisa ser maior que a taxa |
| 422 | <code>insufficient_balance</code> | Saldo disponível insuficiente |
| 429 | <code>rate_limit_exceeded</code> | Limite de 60 requisições/minuto excedido |
| 503 | <code>payout_rules_not_configured</code> | Saque indisponível no momento |
