title: Consultar Saque
description: Retorna os dados completos de um saque
api: "GET /payouts/{id}"
---

## Descrição

Retorna os dados completos de um saque, incluindo status, chave PIX mascarada e taxa. Use para acompanhar o saque quando o webhook não chegar.

---

## Parâmetros de Path

<ParamField path="id" type="string" required>
  UUID do saque, devolvido na criação
</ParamField>

---

## Headers

<ParamField header="Authorization" type="string" required default="Bearer YOUR_API_KEY">
  Bearer token de autenticação. Formato: `Bearer YOUR_API_KEY`
</ParamField>

---

## Exemplo de Requisição

<CodeGroup>
```bash cURL
curl https://api.visepag.com/v1/payouts/aa53d5f9-a2fb-4c29-b36a-f1a2ef03fd30 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch(
  'https://api.visepag.com/v1/payouts/aa53d5f9-a2fb-4c29-b36a-f1a2ef03fd30',
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);
const payout = await response.json();
```

```python Python
import requests

payout = requests.get(
    'https://api.visepag.com/v1/payouts/aa53d5f9-a2fb-4c29-b36a-f1a2ef03fd30',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
).json()
```
</CodeGroup>

## Resposta `200 OK`

<ResponseField name="id" type="string">
  UUID do saque.
</ResponseField>

<ResponseField name="status" type="string">
  Status atual: `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="amount" type="integer">
  Valor do saque em centavos (o que saiu do saldo).
</ResponseField>

<ResponseField name="platformFee" type="integer">
  Taxa do saque, em centavos.
</ResponseField>

<ResponseField name="description" type="string">
  Descrição do saque.
</ResponseField>

<ResponseField name="pixType" type="string">
  Tipo da chave PIX: `cpf`, `cnpj`, `phone`, `email` ou `random`.
</ResponseField>

<ResponseField name="pixMasked" type="string">
  Chave PIX de destino mascarada.
</ResponseField>

<ResponseField name="failureReason" type="string | null">
  Motivo da falha, só quando `status` é `failed`.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data de criação em ISO 8601.
</ResponseField>

<ResponseField name="completedAt" type="string | null">
  Data de conclusão em ISO 8601, ou `null`.
</ResponseField>

<ResponseField name="failedAt" type="string | null">
  Data da falha em ISO 8601, ou `null`.
</ResponseField>

<ResponseField name="currency" type="string">
  Sempre `"brl"`.
</ResponseField>

## Erros

| Status | Código | Descrição |
|--------|--------|-----------|
| `404` | `payout_not_found` | Saque não encontrado, ou de outra empresa |
| `401` | `missing_authorization` | Header `Authorization` ausente |
