## Pré-requisitos

- Uma conta ativa na [VisePag](https://dash.visepag.com/login)
- Sua API Key (disponível no Dashboard, no menu **API**)

---

## Passo 1 — Criar uma Cobrança PIX

Faça um `POST /v1/payins` com o valor em **centavos**:

<CodeGroup>
```bash cURL
curl -X POST https://api.visepag.com/v1/payins \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 1000,
    "description": "Pedido #1234",
    "customerName": "João Silva",
    "customerDocument": "52998224725",
    "customerEmail": "joao@email.com"
  }'
```

```javascript Node.js
const response = await fetch('https://api.visepag.com/v1/payins', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 1000, // R$ 10,00 em centavos
    description: 'Pedido #1234',
    customerName: 'João Silva',
    customerDocument: '52998224725',
    customerEmail: 'joao@email.com'
  })
});

const charge = await response.json();
```

```python Python
import requests

charge = requests.post(
    'https://api.visepag.com/v1/payins',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'amount': 1000,  # R$ 10,00 em centavos
        'description': 'Pedido #1234',
        'customerName': 'João Silva',
        'customerDocument': '52998224725',
        'customerEmail': 'joao@email.com'
    }
).json()
```
</CodeGroup>

<Warning>
  O campo `amount` é sempre em <strong>centavos</strong>. Para cobrar R$ 10,00, envie `1000`.
</Warning>

**Resposta:**

```json
{
  "id": "54e2b712-aca0-4230-b69a-d6dd8542c925",
  "status": "pending",
  "method": "pix",
  "amount": 1000,
  "expiresAt": "2026-03-06T18:14:48Z",
  "pixCopy": "00020101021226..."
}
```

---

## Passo 2 — Exibir o QR Code para o cliente

Use o campo `pixCopy` para exibir o código PIX copia-e-cola, ou o `pixQrCode` (imagem do QR Code).

```javascript
console.log(charge.pixCopy);
```

---

## Passo 3 — Verificar o Status

Consulte o status da cobrança via polling ou configure um [Webhook](/concepts/webhooks):

```bash
curl https://api.visepag.com/v1/payins/54e2b712-aca0-4230-b69a-d6dd8542c925 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json
{
  "id": "54e2b712-aca0-4230-b69a-d6dd8542c925",
  "status": "paid",
  "paidAt": "2026-03-05T18:16:22Z"
}
```
