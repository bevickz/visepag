## O que são Webhooks?

Webhooks são notificações HTTP enviadas automaticamente pela VisePag para a URL configurada no seu sistema quando um evento ocorre (ex: pagamento confirmado, saque concluído).

## Eventos Suportados

| Evento | Descrição |
|--------|-----------|
| `transaction.paid` | Pagamento PIX confirmado |
| `withdrawal.completed` | Saque processado com sucesso |
| `withdrawal.failed` | Saque falhou |

Os endpoints são cadastrados no Dashboard, no menu **Webhooks**. Veja [Webhooks na API Reference](/api-reference/webhooks/overview) para a assinatura.

## Respondendo ao Webhook

Sua URL deve responder com qualquer **HTTP 2xx** em até **10 segundos**:

```javascript
// Exemplo com Express.js
app.post('/webhooks/visepag', (req, res) => {
  const { id, type, data } = req.body;

  // Processar o evento de forma assíncrona
  processarEvento(id, type, data).catch(console.error);

  // Responder imediatamente
  res.status(200).end();
});
```

<Warning>
  Processe a lógica de negócio de forma assíncrona. Se sua URL demorar mais de 10 segundos ou não responder 2xx, o webhook será considerado falho e retentativas serão feitas em 30 s, 2 min, 10 min, 30 min, 1 h, 3 h e 6 h.
</Warning>

## Boas Práticas

- **Seja idempotente:** o mesmo evento pode ser entregue mais de uma vez. Use o `id` do evento (header `X-Event-Id`) para evitar processamento duplicado
- **Responda rápido:** retorne `200` imediatamente e processe em background
- **Valide o payload:** verifique se o `id` existe no seu sistema antes de processar
